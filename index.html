🔍 จับคู่สินค้ากับ SKU
💡 จับคู่ตาม สินค้า (รหัส 1688 · ร้าน · ชื่อสินค้า) + สเปกสี/ไซส์ จาก Vcanbuy — เลือกรุ่นของเราครั้งเดียวต่อสินค้า แล้วยืนยันสี · ยืนยันแล้วระบบจำไว้ ครั้งหน้าจับคู่ให้เอง (🧠) · 💡 = เดาจากข้อมูลเก่า ต้องกดยืนยัน
✅ ผลลัพธ์สุดท้าย (รวมข้อมูลกล่องพัสดุ)
Orderกล่องพัสดุรหัสสินค้าSKU ชื่อสินค้าสีจำนวน ราคา/ชิ้น(฿)ขนส่งจีน-จีนขนส่งจีน-ไทย ค่าบริการค่าบริการนำส่งค่าบรรจุภัณฑ์ ขนส่งไทย-ไทยราคาชิ้นละ(หลังรวม)ราคารวมสุทธิ
📋 Export to VCANBUY — ใบกำกับภาษี
ℹ️ รวมรหัสสินค้าเดียวกันทุก Order ในบิลขนส่งเดียวกัน เป็นรายการเดียว — ราคา/หน่วย = ราคาเฉลี่ยถ่วงน้ำหนัก · วันที่ในใบ = วันที่เปิดบิลขนส่ง
ลำดับ รายการสินค้า จำนวน หน่วย ราคา/หน่วย รวมทั้งหมด
📊 Export to Peak — นำเข้าสินค้าคงคลัง
ℹ️ รวม SKU เดียวกันทุก Order ในบิลขนส่งเดียวกัน — 1 บรรทัดต่อ 1 SKU (สี) — ราคาต่อหน่วย = weighted average · 1 บิล = 1 เอกสาร Peak (อ้างอิง = เลขบิล)
